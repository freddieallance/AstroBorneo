# AstroBorneo: Mission Survival Academy

AstroBorneo: Mission Survival Academy is an interactive, visual-first Moon-base survival game designed for children aged 7–12. Players explore a lunar base, complete picture-based challenges, and make engineering decisions to keep astronauts safe. Through resource management, mission events, and NASA scientific resources, AstroBorneo transforms complex space-survival concepts into a fun, accessible STEM learning experience.
